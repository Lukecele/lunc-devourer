# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities directly via:
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### Scope
- Frontend client interface code in this repository
- Mathematical calculation models (`DevourCalculator.tsx`)
