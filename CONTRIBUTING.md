# Contributing to LUNC Devourer Showcase

We welcome open-source contributions to enhance this Web3 burn simulator and dApp design showcase.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Verify that builds succeed cleanly: `npm run build`.
4. Open a Pull Request with a clear description of the changes.
